# Mapstone

## 최근 작업 · v0.9.57

### 선·화살표 편집과 선 두께

- 선이나 화살표를 선택하면 양 끝점에 조절 핸들이 나타납니다. 시작점과 종료점을 각각 움직여 각도와 길이를 자유롭게 바꿀 수 있으며, 끝점을 서로 교차하거나 수평·수직으로 맞출 수 있습니다.
- 끝점을 드래그할 때 `Shift`를 누르면 방향을 45도 단위로 고정합니다. 끝점에 키보드 초점을 두고 방향키를 누르면 1px, `Shift`와 함께 누르면 10px씩 움직입니다.
- 한 번의 드래그는 한 번의 실행 취소로 되돌릴 수 있습니다. 잠긴 도형과 읽기 전용 일정에서는 끝점을 조절할 수 없습니다.
- 사각형·타원·마름모·선·화살표의 선 두께를 속성 패널에서 조절합니다. 디자인 시스템을 적용한 **− / ＋ 버튼**과 **숫자 입력**을 제공하며, 범위는 **1–12px**입니다. 여러 도형을 선택하면 함께 적용됩니다.
- 조정한 선의 끝점·방향·두께는 파일 저장과 불러오기, 버전 비교 이미지, PPTX 내보내기에 반영됩니다.

### 버전 복원 전 미저장 변경 확인

현재 일정이 버전으로 저장된 내용과 다르면 **이 버전으로 복원**을 누를 때 다음 확인창을 표시합니다. 브라우저 자동 저장과 버전 저장은 별개입니다.

> 현재까지 작업한 내용이 저장되어 있지 않습니다. 그래도 진행하시겠습니까?

취소하면 현재 작업을 유지하며, 진행한 복원은 실행 취소할 수 있습니다. 이전 버전을 복원한 뒤 새로고침해도 저장 상태를 판정합니다. 버전을 불러오는 동안 새로 편집한 내용이 생기면 복원을 중단하고 안내합니다.

### 버전 저장 실패 안내

- 인터넷 연결 실패, 서버 응답 시간 초과, 브라우저 저장 공간·권한, 보관함 접근 키 불일치, 데이터 크기 제한, 요청 횟수 제한, 서버 오류를 구분해 원인과 다음 조치를 안내합니다.
- 서버에서는 버전 저장 테이블·함수의 미적용 마이그레이션, 데이터베이스 접근 권한, 동시 저장 충돌도 구분해 안내합니다.
- 저장 요청은 성공했지만 버전 목록을 새로 불러오지 못한 경우에는 **버전은 저장되었지만 목록을 새로 불러오지 못했습니다**라고 안내하고 저장된 버전 카드를 유지합니다.
- 저장에 실패하면 입력 메모를 보존합니다. 저장 중 새로 입력한 메모도 지우지 않습니다. 연결 끊김·시간 초과로 결과를 알 수 없으면 저장 여부를 확인할 수 없다고 안내합니다.

### 검증과 반영 상태

- 빌드 및 테스트 **363개 통과**. Chromium에서 다섯 도형의 두께 입력·증감, 선·화살표 양 끝점 이동, 새로고침 유지, 복원 확인창 취소·진행, 오류 응답 안내를 확인했습니다.
- 격리된 테스트 일정 8개·42개 아이템으로 메인 배율·비교 오버랩·슬라이드 구분선을 각각 3회 이상 연속 드래그했습니다. 측정된 프레임 간격 p95는 최대 33.4ms, 50ms 초과는 0회였습니다. 확대·스크롤·분석 패널 열림 조건도 확인했습니다. 이는 headless 브라우저 입력 측정이며 사용자 실사용 환경의 체감 성능을 보장하지 않습니다.
- 기능 변경 커밋: `7a2deab` (`957 선 끝점 자유 조정 및 버전 저장·복원 개선`). 기능 수정과 README 업데이트를 GitHub `main`에 반영했습니다. 운영 배포 완료 여부는 별도 확인이 필요합니다.
- 서버의 상세 오류 안내는 웹 프런트엔드와 Supabase Edge Function 배포 후 운영에 적용됩니다. 운영 DB의 실제 저장 장애 원인과 설정 상태는 아직 확인하지 않았으며, 오류 흐름은 재현 응답으로 검증했습니다.

## 이미지 · 텍스트 일정 분석

**가져오기** 창에서 마일스톤이 담긴 이미지(간트 차트, 로드맵, 표, 캡처, 손그림 등)나 텍스트(회의록, 메일, PRD, 표 복사본 등)를 파일 추가, 끌어놓기, 붙여넣기로 넣고 분석하면 구분 행, 블록, 마일스톤, 이슈, 공통 구간, 메모와 색상까지 Mapstone 일정으로 변환합니다. 결과를 검토한 뒤 교체하며, 기존 일정은 JSON으로 백업됩니다. 분석 호출은 Supabase Edge Function에서 처리하며 접속 코드 없이도 사용할 수 있습니다(코드 미연결 시 IP당 시간당 20회 제한). 비용 상한은 Gemini/OpenAI 키의 사용량 한도로 설정하세요. Mapstone JSON/JavaScript 데이터는 연결 없이 바로 가져옵니다. 이미지는 **참조 이미지로만 추가**할 수도 있습니다.

운영 환경의 Supabase Edge Function Secrets에 `GEMINI_API_KEY`(Google, 우선 사용) 또는 `OPENAI_API_KEY`를 설정해야 합니다. 모델은 `GEMINI_MODEL`(기본 `gemini-3.8-flash`) 또는 `OPENAI_VISION_MODEL`(기본 `gpt-4.1-mini`)로 바꿀 수 있습니다.

브라우저에서 개발 일정을 편집하고 PNG, PPTX, PDF, 텍스트로 내보내는 일정 보드입니다. `index.html`은 외부 CDN 없이 실행되는 단일 파일 배포본입니다.

## 사용

- `index.html`을 열거나 정적 웹 서버에 배포합니다.
- 로컬 일정은 브라우저에 자동 저장됩니다.
- **접속 코드 · DB**에서 같은 편집 코드를 입력한 사용자는 동일한 일정을 편집합니다.
- **가져오기**에서 이미지·텍스트를 AI로 분석하거나, 참조 이미지 또는 JavaScript/JSON 일정 데이터를 검토한 뒤 적용합니다.
- **보기 > 일자**는 날짜를 `MM.DD`로 표시합니다. 메모 속성의 **날짜 미표기**로 개별 메모의 날짜를 숨깁니다.
- `⌘` 클릭으로 여러 항목을 선택·해제하고, `Shift` 클릭으로 범위를 선택하거나 빈 영역을 드래그해 선택합니다. 선택한 항목은 방향키·마우스로 함께 이동하고 복사·잘라내기·붙여넣기·삭제할 수 있습니다.
- **내보내기 > 링크 생성**은 현재 일정을 서버에 사본으로 저장합니다. 생성한 링크에서 보기 전용으로 바로 열리며, 이후 편집 내용은 새 링크를 만들 때 반영됩니다. 다른 사람에게 전달할 링크는 배포된 사이트에서 생성하세요.
- **전체보기**는 도구와 속성 패널을 숨기고 일정만 화면에 맞춥니다. `F` 또는 `Esc`로 돌아옵니다.

## 개발

편집 원본은 `src/timeline.dc.html`입니다. 다음 명령은 단일 파일과 공유용 HTML을 같은 원본에서 다시 만듭니다.
화면 확인·사용자 안내 링크는 반드시 루트의 `index.html`을 사용합니다. `.dc.html`과 `share/schedule-maker.html`은 실행용 파일이 아니며, 직접 열면 `index.html`로 자동 이동합니다. 수정 후에는 빌드와 테스트를 완료한 뒤 실행 화면을 확인합니다.

```bash
npm run build
npm test
```

Supabase DB와 함수 소스는 `supabase/`에 있습니다. 브라우저는 테이블에 직접 접근하지 않으며 Edge Function을 통해서만 읽고 씁니다. 배포된 함수 주소와 데이터 계약은 [docs/API.md](docs/API.md)를 참고하세요.

관리자 키는 `.mapstone-admin-key`에 로컬로 생성되며 Git에서 제외됩니다. 키를 잃으면 DB의 `mapstone_admin.key_hash`를 새 키의 SHA-256 값으로 교체해야 합니다.
