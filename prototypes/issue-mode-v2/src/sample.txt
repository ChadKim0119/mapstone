27CY SU#2 2차 DVT 진입과 관련하여, 현재까지 확인된 주요 이슈와 테스트 환경 구성 현황, GS(Global South) 및 e-Care 영역별 테스트 수행 가능 범위를 공유드립니다.
현재 2차 DVT는 Global South의 DCM ADF 수행 오류와 e-Care의 VDP API 인증 문제 등 주요 연계 환경의 정상화가 필요한 상황입니다.
특히 1차 DVT에서 수행하지 못했던 N/T 및 Fail 항목에 대한 재검증을 진행하기 위해서는 관련 선행 조건의 해결이 필요하며, 해당 문제의 해결 여부에 따라 2차 DVT의 실제 테스트 수행 범위와 결과가 크게 달라질 것으로 판단됩니다.
이에 따라 현재 진행 상황 및 향후 대응 계획을 아래와 같이 정리하였습니다.

2.3 ADF 수행 결과에 따른 2차 DVT 영향
① ADF 정상 수행 시
금일 전달되는 DCM에서 ADF가 정상적으로 수행될 경우, 1차 DVT에서 DCM 환경 문제로 Block되었던 Global South 관련 N/T 및 Fail 항목 대부분에 대한 재검증이 가능할 것으로 판단됩니다.
특히 ADF 선행 작업이 필요한 50건에 대해 테스트 가능 여부를 재확인할 수 있으며, DCM을 활용한 REST/MQTT 및 차량 기반 업무 Flow 검증도 진행할 수 있을 것으로 예상됩니다.
다만 HU 환경, DK 서버 연동 등 별도 선행 조건이 필요한 항목은 해당 환경이 추가로 확보되어야 합니다.
② ADF 수행 실패 시
반면 전달받은 DCM 2대 모두 ADF 수행에 실패할 경우, 현재와 동일하게 DCM 기반 테스트 환경을 확보하지 못하게 됩니다.
이에 따라 1차 DVT에서 Block되었던 DCM 연계 N/T 항목은 2차 DVT에서도 테스트가 제한되며, 관련 Fail 항목의 재검증 또한 어려울 것으로 예상됩니다.
결과적으로 DCM의 ADF 문제가 해결되지 않을 경우 Global South의 2차 DVT 결과는 1차 DVT와 비교하여 유의미한 차이가 발생하지 않을 가능성이 높습니다.
따라서 대체 DCM의 ADF 정상 수행 여부를 최우선으로 확인하고, 그 결과에 따라 Global South의 2차 DVT 테스트 수행 범위를 확정할 예정입니다.

3.4 2차 DVT 영향
VDP는 e-Care 서비스의 주요 연계 시스템으로, 관련 API가 정상적으로 동작하지 않을 경우 VDP/VEP 연계 및 관련 업무 Flow에 대한 E2E 검증이 제한됩니다.
또한 2차 DVT에서는 1차 DVT에서 진행하지 못한 DMS 연동 시나리오까지 검증할 예정이므로, VDP 연계가 필요한 테스트 항목은 API 정상 동작 여부가 선행 조건입니다.
현재 TCP 연결까지는 확인되었으나 실제 API 호출이 정상적으로 수행되지 않고 있어, 관련 테스트 진행이 제한되는 상황입니다.
따라서 일본 측의 API 인증 정책 확인 및 오류 해결이 2차 DVT의 e-Care 연계 검증을 위한 주요 선행 조건으로 판단됩니다.
4. DMS 인터페이스 테스트 계획
4.1 테스트 대상 및 범위
2차 DVT에서는 DMS 인터페이스 총 24개 API에 대한 테스트를 진행할 예정입니다.
기존 1차 DVT에서 진행하지 못했던 DMS 연동 항목까지 포함하여 테스트 범위를 확대할 계획입니다.
주요 테스트 범위
DMS 연동 API 24개에 대한 요청/응답 검증
인터페이스별 데이터 정합성 확인
1차 DVT 미수행 DMS 연동 항목 테스트
DMS와 관련 시스템 간 업무 Flow 검증
VDP 연계가 필요한 항목에 대한 E2E 검증
4.2 테스트 선행 조건
DMS API 단위 테스트와 전체 업무 Flow에 대한 E2E 검증은 구분하여 진행할 예정입니다.
특히 VDP와 연계되는 업무 시나리오는 VDP API가 정상적으로 동작해야 실제 E2E 테스트 수행이 가능합니다.
따라서 현재 발생 중인 VDP 인증 오류가 해결되지 않을 경우, DMS 연동 테스트 중 일부 항목의 검증 범위가 제한될 수 있습니다.
이에 따라 DMS 테스트는 API 단위 검증이 가능한 항목부터 진행하고, VDP 연계가 필요한 항목은 관련 환경 정상화 이후 진행하는 방향으로 검토할 예정입니다.

현재 Global South에서 가장 큰 비중을 차지하는 제약 사항은 ADF 선행 작업이 필요한 50건입니다.
따라서 대체 DCM의 ADF 수행이 정상화된다면 해당 항목의 테스트 가능 여부를 우선 재검토할 예정입니다.
다만 HU 환경 구성 22건 및 DK 서버 연동 미구현 2건 등은 ADF 정상화만으로 해결되지 않는 별도 제약 사항이므로 추가 대응이 필요합니다.

CCW는 현재 QA 기준 수행 불가 건수가 가장 많은 영역으로, 테스트 환경 확보 일정 및 담당 주체에 대한 확인이 필요합니다.

8. 종합 의견
현재 2차 DVT는 1차 DVT에서 수행하지 못한 항목에 대한 재검증과 시스템 간 E2E 테스트 확대를 목표로 진행하고 있으나, 주요 연계 환경이 완전히 확보되지 않아 테스트 수행 범위에 제약이 있는 상황입니다.
특히 다음 사항이 중요하다고 판단됩니다.
첫째, Global South의 DCM ADF 정상 수행 여부입니다.
금일 확보하는 대체 DCM에서 ADF가 정상적으로 수행될 경우 1차 DVT에서 Block되었던 DCM 연계 N/T 및 Fail 항목 대부분에 대한 재검증이 가능할 것으로 판단됩니다.
반면 2대 모두 ADF 수행에 실패할 경우 기존과 동일한 환경 제약이 지속되어, 2차 DVT의 Global South 검증 결과는 1차 DVT와 큰 차이가 없을 것으로 예상됩니다.
둘째, e-Care의 VDP API 인증 문제입니다.
VDP는 9월 30일부터 일본 측과 접속 정보 및 인증 방식에 대한 협의를 진행하였으나, 접속 대상 안내 변경과 인증 방식 확인 지연으로 10월 20일 현재까지 실제 API 연동 검증이 완료되지 못하였습니다.
현재 네트워크 연결은 정상적으로 확인되었으나 API 인증 오류가 해결되지 않아 관련 E2E 테스트가 제한되고 있습니다.
셋째, CCW 및 기타 테스트 환경 확보입니다.
QA 검토 결과 e-Care CCW는 236건 전체가 테스트 수행 불가 상태이며, Global South의 HU 환경 및 DK 서버 연동 등 별도 선행 조건이 필요한 항목도 존재합니다.
따라서 DCM 및 VDP 문제가 해결되더라도 CCW, HU, DK 등 개별 환경 제약 사항은 별도로 해소되어야 합니다.
결론적으로, 현재의 주요 Blocker가 해결되지 않은 상태에서 2차 DVT를 진행할 경우 1차 DVT와 유사한 N/T 및 Fail 결과가 반복될 가능성이 있습니다.
이에 따라 테스트 자체의 진행 여부보다는, 실제 검증이 가능한 환경을 확보하고 선행 조건이 해결된 항목을 중심으로 테스트를 진행하는 것이 필요하다고 판단됩니다.
우선 DCM ADF 및 VDP API 정상 동작 여부를 확인하고, CCW와 DMS 등 관련 연계 환경의 확보 일정에 따라 2차 DVT의 최종 수행 가능 범위와 제한 사항을 확정할 예정입니다.
아울러 현재 테스트 수행이 불가능한 항목은 기능 자체의 결함 여부와 테스트 환경 및 선행 조건 미충족에 따른 제약 사항을 구분하여 관리할 필요가 있습니다.
관련 부문에서는 각 선행 조건의 해결 가능 여부와 예상 조치 일정을 확인하여 공유 부탁드립니다.
TC별 상세 수행 가능 여부 및 N/T 사유는 첨부한 GS 및 e-Care DVT TC 목록을 참고하여 주시기 바랍니다.
