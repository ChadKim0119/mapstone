# 버전 비교 워크스페이스 (v0.9.51)

오버랩 비교와 폭 맞춤이 기본이다. 상단은 기준 전환·이미지 저장만 남긴 작은 도구 막대이며, 보기 도구는 일정표 하단에 떠 있다. 변경 목록과 AI 분석은 요청할 때 오른쪽 패널로 열린다.

- 기준 V1 → 비교 V2: 기준 바꾸기가 이미지·목록·저장 방향을 함께 바꾼다.
- 오버랩 비교 / 슬라이드 비교: 오버랩은 비교 버전의 불투명도를, 슬라이드는 구분선을 조절한다. 구분선은 포인터와 방향키·Home/End를 지원한다. 메인 배율·오버랩·구분선 모두 Shift+좌우 방향키로 일반 단계의 10배를 이동한다.
- 폭 맞춤 앞 구분선으로 비교 방식과 크기 도구를 구분한다. 폭 맞춤 / 전체 맞춤 / 원본 크기와 확대·축소를 제공한다.
- 변경 표시: 초록 추가·빨간 점선 삭제·파랑 변경. 범례는 12px, 이미지 변경 테두리는 #3568c5 파란색이다.
- 변경 비교 이미지 저장: 변경 테두리·범례·변경 내역을 포함한 기존 PNG 출력. 현재 보기 PNG와 별도 버전 저장 버튼은 제거했다. 현재 작업은 바꾸지 않는다.
- 변경·분석: 기본 닫힘. 전체보기/접기로 패널 너비를 전환한다. Escape는 전체보기 해제 → 패널 닫기 순서로 동작한다.
- 분석 진행 화면과 요약 보고서는 좁은 패널에서도 한 열로 표시한다. 문구는 단어 단위로 줄바꿈한다. 로컬 버전의 AI 제한 이유를 안내한다.
- 비교 버튼은 마우스 진입·키보드 초점 시 공통 설명 툴팁을 제공한다. 툴팁은 대화상자 안에 배치해 최상위 레이어 뒤에 가려지지 않게 한다.

비동기 출력 중 버튼을 잠그고 결과·실패 원인을 표시한다. PNG 다시 다운로드 링크는 표시하지 않는다. 비교 화면의 backdrop blur는 사용하지 않는다.

## v0.9.51 변경점 탐색·조작 확인 (2026-10-18)

- 요약 목록과 전체 상세 보고서에 항목별 ‘이동’을 제공한다. 분석 패널을 접고 오버랩 100%로 변경점을 선명하게 보여주며, 항목 테두리에 실제 키보드 초점을 옮긴다. 삭제 항목은 기준 버전의 좌표를 사용한다. 세션은 해당 행, 문서 기간·제목은 헤더를 강조한다.
- 슬라이드 진입·확대·스크롤 시 현재 보이는 이미지 영역의 가운데로 구분선과 핸들을 배치한다. 핸들 높이는 전체 이미지의 중앙이 아닌 화면 안의 중앙이다. 첫 슬라이드 진입에서 선과 핸들을 1.2초씩 3회 breathing하며, 조작 시 즉시 멈춘다. 모션 끄기·OS 모션 감소를 존중한다.
- 도구는 비교 방식·크기·배율 그룹으로 묶고 그룹 안 6px/그룹 간 8px 간격을 사용한다. 데스크톱에서 분석 패널이 열리면 도구 막대를 가려지지 않는 영역으로 옮긴다. 재시도는 내용에 맞는 작은 버튼이다.

## v0.9.50 정합·패널 개선 확인 (2026-10-18)

- 비교 레이어는 같은 마일스톤 영역·행 높이·헤더 높이·캔버스 크기를 사용한다. 추가/삭제 마일스톤과 큰 포스트잇 때문에 한 레이어가 늘어나지 않도록 공통 크기를 산출한다.
- 마일스톤 날짜는 편집기의 `markerMetadata` 좌표에 따로 그린다. 본체 안의 아이콘/라벨 배치에는 날짜 폭을 더하지 않는다. 라벨의 실제 크기·굵기·여러 줄을 반영한다.
- 헤더 높이는 주차 표시 시 44px, 미표시 시 36px이다. 비교에서는 두 버전 중 큰 높이를 공통으로 사용한다. 헤더 하단 10px 여백·얇은 선을 본 화면과 SVG에 반영한다.
- 기간·날짜는 편집기의 `itemMetadata`를 재사용한다. 포스트잇 아래에 임의의 날짜를 붙이지 않는다. 마일스톤 세로 기준선도 편집기와 같이 표시한다.
- 분석 패널 상단은 제목과 ‘전체보기/닫기’ 도구, 그 아래는 ‘변경 목록/AI 분석’ 기능 탭이다. 두 영역을 선으로 구분하고 본문·카드 패딩은 각각 14px로 정리한다. 요약 영역에 덮이던 공통 선택 배경색도 제거했다.

## 이전 v0.9.48 UX·이미지 검수 (2026-10-18)

적용 스킬: `ux-auditor`, `design:design-critique`. 사용자 요청으로 아래 개선을 적용한 후 실제 브라우저와 출력 이미지를 재검수했다. 별도 이미지 생성은 필요하지 않았다.

첫인상·위계: 기존 화면은 큰 설정 영역과 항상 열린 보고서가 일정표보다 강했다. 일정표를 가장 넓은 영역으로 만들고, 자주 쓰는 보기 조작은 작은 플로팅 막대로 묶었다. 기본 화면에서 추가·삭제·변경을 즉시 확인하고 세부 설명은 필요할 때 연다. 기존 제품의 색·버튼 스타일을 유지했다.
