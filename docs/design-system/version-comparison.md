# 버전 비교 워크스페이스 (v0.9.48)

변경 강조와 폭 맞춤을 기본으로 사용한다. 상단은 기준 전환·결과 저장만 남긴 작은 도구 막대이며, 보기 도구는 일정표 하단에 떠 있다. 변경 목록과 AI 분석은 요청할 때 오른쪽 패널로 열린다. 일정표와 패널은 각각 스크롤한다.

- 기준 V1 → 비교 V2: 기준 바꾸기가 이미지·목록·저장 방향을 함께 바꾼다.
- 변경 강조 / 슬라이드 비교 / 오버랩 비교: 추가·삭제·변경 표시를 켜고 끌 수 있다. 삭제는 빨간 점선으로도 구분한다.
- 슬라이드 구분선: 포인터와 방향키, Home/End로 조절한다. 오버랩은 비교 버전의 불투명도만 조절한다.
- 폭 맞춤 / 전체 맞춤 / 원본 크기와 확대·축소: 표시 배율을 조정한다. 확대된 일정표는 내부에서 스크롤한다.
- 변경·분석: 기본 닫힘. 패널을 연 상태에서 Escape를 누르면 패널부터 닫힌다. 로컬 버전은 AI 분석이 비활성인 이유를 표시한다.
- 변경 반영 버전 저장: 비교 방향을 반영한 별도 스냅샷. 현재 작업을 유지하고 읽기 전용에서는 저장을 막는다.
- 변경 반영 이미지: 변경 표시·범례·변경 내역을 포함한 기존 PNG 출력.
- 현재 보기 PNG: 현재 비교 모드·불투명도·변경 표시를 적용한 전체 일정표. 도구·패널과 화면 스크롤 위치는 포함하지 않는다. 최대 긴 변 4,096px, 최대 2배로 출력한다.

색상·표면·모서리는 기존 토큰을 재사용한다. 비동기 저장·출력 중 버튼을 잠그고 결과·실패 원인과 다시 다운로드 링크를 표시한다. 비교 화면의 backdrop blur는 사용하지 않는다.

## UX·이미지 검수 (2026-10-18)

적용 스킬: `ux-auditor`, `design:design-critique`. 사용자 요청으로 아래 개선을 적용한 후 실제 브라우저와 출력 이미지를 재검수했다. 별도 이미지 생성은 필요하지 않았다.

첫인상·위계: 기존 화면은 큰 설정 영역과 항상 열린 보고서가 일정표보다 강했다. 일정표를 가장 넓은 영역으로 만들고, 자주 쓰는 보기 조작은 작은 플로팅 막대로 묶었다. 기본 화면에서 추가·삭제·변경을 즉시 확인하고 세부 설명은 필요할 때 연다. 기존 제품의 색·버튼 스타일을 유지했다.

- [ ] UX-001 · 높음 · 상단·고정 보고서가 일정표 공간을 압박 → 상단 압축, 보고서 기본 닫힘으로 해결.
- [ ] UX-002 · 높음 · 작은 고정 이미지로 변경을 읽기 어려움 → 폭 맞춤 기본, 전체/원본 보기와 확대·축소로 해결.
- [ ] UX-003 · 보통 · 화면에서 선택한 비교 표현을 결과 이미지로 얻기 어려움 → 현재 보기 PNG로 해결. 기존 결과 저장 버튼도 유지.
