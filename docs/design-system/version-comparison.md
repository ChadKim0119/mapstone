# 버전 비교 워크스페이스 (v0.9.40)

오버랩 비교가 기본이다. 이미지와 변경 목록은 두 열로 배치하고, 좁은 화면에서는 세로 배치한다. 전체 모달에 중첩된 스크롤 대신 이미지의 원본 크기 보기와 오른쪽 콘텐츠 영역에만 스크롤을 둔다.

- 헤드메시지: 기준 → 비교 버전. 기준 선택 변경 시 목록·이미지·저장 결과도 함께 변경한다.
- 기준 선택: 키보드로 열 수 있는 details/summary와 이름이 있는 select.
- 불투명도: 우측 툴바. 기준 이미지는 유지하고 비교 이미지의 불투명도를 조절한다.
- 변경 목록 / AI 분석: aria-pressed 버튼으로 패널을 전환한다.
- 변경 표시: 추가·삭제·변경을 색상, 점선, 분류 텍스트로 함께 구별한다.
- 변경 반영 버전 저장: 비교 방향의 모든 변경을 반영한 별도 스냅샷. 현재 작업은 유지한다. 읽기 전용에서는 저장을 막는다.
- 변경 반영 이미지: 반영된 일정의 PNG. 다운로드 링크를 함께 제공한다.
- 슬라이드: 가운데 핸들 방향키·포인터 조절. 애니메이션 설정과 OS reduced motion을 존중하며 breathing 효과를 적용한다.

색상·간격·테두리·표면은 기존 ms-color, ms-space, ms-radius 토큰을 사용한다. 비동기 저장·이미지 출력은 실행 중 버튼을 잠그고 상태와 실패 원인을 표시한다. AI 기능은 기존 클라우드 버전 경로를 사용한다.
