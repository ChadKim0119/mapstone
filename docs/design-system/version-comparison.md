# 버전 비교 워크스페이스 (v0.9.49)

오버랩 비교와 폭 맞춤이 기본이다. 상단은 기준 전환·이미지 저장만 남긴 작은 도구 막대이며, 보기 도구는 일정표 하단에 떠 있다. 변경 목록과 AI 분석은 요청할 때 오른쪽 패널로 열린다.

- 기준 V1 → 비교 V2: 기준 바꾸기가 이미지·목록·저장 방향을 함께 바꾼다.
- 오버랩 비교 / 슬라이드 비교: 오버랩은 비교 버전의 불투명도를, 슬라이드는 구분선을 조절한다. 구분선은 포인터와 방향키·Home/End를 지원한다.
- 폭 맞춤 앞 구분선으로 비교 방식과 크기 도구를 구분한다. 폭 맞춤 / 전체 맞춤 / 원본 크기와 확대·축소를 제공한다.
- 변경 표시: 초록 추가·빨간 점선 삭제·주황 변경. 범례는 12px, 이미지 변경 테두리는 #f58220 주황색이다.
- 변경 비교 이미지 저장: 변경 테두리·범례·변경 내역을 포함한 기존 PNG 출력. 현재 보기 PNG와 별도 버전 저장 버튼은 제거했다. 현재 작업은 바꾸지 않는다.
- 변경·분석: 기본 닫힘. 전체보기/접기로 패널 너비를 전환한다. Escape는 전체보기 해제 → 패널 닫기 순서로 동작한다.
- 분석 진행 화면과 요약 보고서는 좁은 패널에서도 한 열로 표시한다. 문구는 단어 단위로 줄바꿈한다. 로컬 버전의 AI 제한 이유를 안내한다.
- 비교 버튼은 마우스 진입·키보드 초점 시 공통 설명 툴팁을 제공한다. 툴팁은 대화상자 안에 배치해 최상위 레이어 뒤에 가려지지 않게 한다.

비동기 출력 중 버튼을 잠그고 결과·실패 원인과 다시 다운로드 링크를 표시한다. 비교 화면의 backdrop blur는 사용하지 않는다.

## 이전 v0.9.48 UX·이미지 검수 (2026-10-18)

적용 스킬: `ux-auditor`, `design:design-critique`. 사용자 요청으로 아래 개선을 적용한 후 실제 브라우저와 출력 이미지를 재검수했다. 별도 이미지 생성은 필요하지 않았다.

첫인상·위계: 기존 화면은 큰 설정 영역과 항상 열린 보고서가 일정표보다 강했다. 일정표를 가장 넓은 영역으로 만들고, 자주 쓰는 보기 조작은 작은 플로팅 막대로 묶었다. 기본 화면에서 추가·삭제·변경을 즉시 확인하고 세부 설명은 필요할 때 연다. 기존 제품의 색·버튼 스타일을 유지했다.

- [ ] UX-001 · 높음 · 상단·고정 보고서가 일정표 공간을 압박 → 상단 압축, 보고서 기본 닫힘으로 해결.
- [ ] UX-002 · 높음 · 작은 고정 이미지로 변경을 읽기 어려움 → 폭 맞춤 기본, 전체/원본 보기와 확대·축소로 해결.
- [ ] UX-003 · 보통 · 화면에서 선택한 비교 표현을 결과 이미지로 얻기 어려움 → 현재 보기 PNG로 해결. 기존 결과 저장 버튼도 유지.
