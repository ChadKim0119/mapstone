# MapStone 1.0 출시 전 점검

점검일: 2026-10-09. 작업 버전: **v0.9.21**. 1.0 버전이나 태그는 생성하지 않았습니다.

## 반영

- 웰컴 로고와 기존 이펙트를 유지하고 요청한 헤드/서브/With MapStone 문구 적용.
- 사용법: 일정 변경과 PPT/엑셀 자료 파편화 문제 → 이미지/텍스트 분석 → 버전 비교 → 아이템 관리 → 공유 → 발표 → 빠른 시작/단축키.
- 실제 구현 화면에서 가상 온보딩 프로젝트로 캡처한 7개 화면 사용. 원본은 assets/help, 안내용 이미지 데이터는 mapstone-help.js에 포함하여 별도 네트워크 요청 없이 제공.
- 현재 화면과 단축키 대조. 발표 G/P/H/Space, 파일 및 AI 분석 결과 검토, 선택 순서와 기준/비교 버전의 의미를 명시.

## 발견 후 수정

1. 짧은 일정 비교에서도 상단 컨트롤을 포함하면 일정표 하단이 잘림: 실제 비교 영역의 화면상 시작 위치를 기준으로 남은 높이에 전체 이미지를 맞춤.
2. 날짜 시작/종료 조절 버튼의 일부 툴팁이 다른 작업을 설명함: 네 버튼의 이름과 툴팁을 실제 동작으로 수정.
3. 버전 선택 체크박스 역할과 상태 속성 불일치: aria-checked 적용.
4. 기존 사용법 캡처/설명이 오래된 화면을 안내함: 실제 캡처와 현재 동작으로 교체. 이미지의 실제 JPEG/PNG 형식에 맞게 MIME 지정.

## 실제 브라우저 검증

사용자의 작업물 대신 별도 로컬 포트 4180의 가상 프로젝트를 사용했습니다. 현재 root index.html 빌드에서 검증했습니다.

| 이미지 분석 | 실제 Gemini 응답: 3세션·5일정·2마일스톤·1메모, 애니메이션/예상 진행률 및 결과 검토 |

| 분석 결과 적용/취소 | 이미지 결과 적용 후 실행 취소로 이전 일정과 저장 버전 복원 |

| 런타임 | 해당 검증 탭 error/warn 로그 없음 |

## 소스 및 자동 검증

- npm run build 성공: 편집 원본에서 root 및 배포 진입점 생성.
- npm test: **206개 통과, 실패 0**.
- node --check mapstone-ui.js 및 git diff --check 통과.
- 비교 크기 계산은 화면상 시작 위치를 포함한 회귀 테스트 추가. ResizeObserver가 자체 높이 변경으로 반복되는 경우도 검증.
- 기존 테스트 범위: 날짜·눈금·이동·리사이즈·행 충돌·메모 연결·실행 취소·파일 왕복·PPT 항목/슬라이드 경계·보기 전용 변경 방지·버전 소유권/복원/삭제·AI 요청 및 중단.
- Git 추적 파일에 .env/개인키 파일 없음 확인. 이 검사는 종합 보안 감사가 아닙니다.

## 1.0 확정 전 남은 출시 확인

- **이번 결과는 로컬 검증입니다.** Git 커밋/푸시와 프로덕션 배포는 이번 작업에서 수행하지 않았습니다. 배포 후 실제 프로덕션 URL에서 핵심 흐름 재확인이 필요합니다.
- 실제 다중 사용자 동시 편집과 PowerPoint 앱에서 내보낸 문서의 시각적 확인은 이번 수동 검증에 포함하지 않았습니다.
- 모바일 viewport 변경 도구가 실제 창 크기에 적용되지 않아 모바일 수동 검증은 확정하지 않습니다. 데스크톱 일정 편집/사용법을 검증했습니다.
- AI 날짜/항목 추출은 결과 검토를 전제로 합니다. 예상 진행률은 실제 서버 처리 퍼센트가 아닙니다.

1.0은 위 출시 확인과 사용자 검토 후 별도 요청에서 지정합니다.
